# CRM سرویک

CRM مستقل سرویک: مکالمات (وویس) به متن تبدیل و تحلیل می‌شوند و کارهای بعدی خودکار یا نیمه‌خودکار انجام می‌شود.

> **داده‌ی مشتری، رمز و کلید هرگز وارد این مخزن نمی‌شود.** داده‌ها فقط در Postgres روی سرور می‌مانند، رمزها و کلیدها فقط در متغیرهای محیطی Coolify.

## چه کار می‌کند

| مرحله | نوع | کجا |
|---|---|---|
| تحلیل مکالمه با مشتری (موارد هفت‌گانه، لحن، مشاوره) | خودکار | آپلود وویس ← مکالمات |
| ثبت سفارش از روی وویس | نیمه‌خودکار (فرم پیش‌پر) | صفحه‌ی مکالمه ← «ثبت سفارش» |
| پخش کار با اولویت سفارش اول و مشتری وفادار | نیمه‌خودکار (پیشنهاد نیرو) | پخش کار |
| نظرسنجی از وویس، شکایت خودکار برای نمره‌ی پایین، کار «تماس مجدد» | نیمه‌خودکار | مکالمه ← تأیید نظرسنجی |
| تماس مجدد با مشتری ناراضی و بستن شکایت | نیمه‌خودکار | شکایت ← آپلود وویس تماس مجدد |
| شکایت متخصصان از وویس | نیمه‌خودکار | آپلود وویس «شکایت متخصص» |
| تیکت متخصصان: پاسخ آماده، پیش‌نویس هوش مصنوعی، کنترل لحن، هشدار دیرکرد | نیمه‌خودکار | تیکت‌ها |
| اشتغال روزانه، ظرفیت و «نیازمند نیرو» | خودکار پس از ثبت اشتغال | اشتغال روزانه، ظرفیت |
| کمیسیون نیم‌بها (روز ۶ و ۷ هفته) | خودکار، تأیید دستی | کمیسیون نیم‌بها |
| کارنامه‌ی کارشناسان و متخصصین | خودکار | گزارش‌ها |
| ورود داده از CRM قدیم و شیت‌ها | دستی (آپلود اکسل) | ورود داده از اکسل |

همه‌ی قوانین (حد شکایت، قانون نیم‌بها، تعریف مشتری وفادار، زمان مجاز پاسخ تیکت، حد «نیازمند نیرو») و همه‌ی فهرست‌ها (موارد هفت‌گانه، معیارهای نظرسنجی، دلایل شکایت) از «تنظیمات و داده‌ها» قابل تغییرند. مقدارهای فعلی پیش‌فرض‌اند و در جلسه‌ی دیپلوی نهایی می‌شوند.

## راه‌اندازی روی Coolify

1. **دیتابیس:** New Resource → Database → PostgreSQL (جدا از پروژه‌های دیگر). آدرس داخلی (Internal URL) را بردارید.
2. **اپلیکیشن:** New Resource → Application → از همین مخزن گیت‌هاب، Build Pack: **Dockerfile**، پورت **8000**.
3. **زیردامنه:** در Domains آدرس را بگذارید (مثلاً `https://crm.example.com`).
4. **Persistent Storage:** یک volume با مسیر `/data/media` اضافه کنید (فایل‌های صوتی این‌جا ذخیره می‌شوند).
5. **Environment Variables** (نام‌ها در `.env.example`):
   - `SECRET_KEY` — یک رشته‌ی تصادفی بلند
   - `DATABASE_URL` — آدرس داخلی Postgres
   - `ALLOWED_HOSTS` — مثلاً `crm.example.com`
   - `CSRF_TRUSTED_ORIGINS` — مثلاً `https://crm.example.com`
   - `OPENROUTER_API_KEY` — کلید جدا برای همین پروژه
   - `INGEST_TOKEN` — (اختیاری) برای ارسال خودکار ضبط‌های جولیو
6. Deploy. در اولین اجرا جدول‌ها و پیش‌فرض‌ها خودکار ساخته می‌شوند.
7. **ساخت مدیر:** در Coolify → Terminal اپلیکیشن: `python manage.py createsuperuser`
8. کارشناس‌ها را از «تنظیمات و داده‌ها ← کاربران» بسازید و برای هر کدام نقش و نام نمایشی بگذارید.

## ورود داده

از منوی «ورود داده از اکسل» این فایل‌ها را آپلود کنید (ترتیب مهم نیست؛ سیستم خودش مرتب می‌کند):
- از CRM قدیم: خروجی «نیروها»، «سفارشات»، «گزارشات مشتریان» (تعداد نمایش در صفحه را زیاد کنید تا همه‌ی ردیف‌ها بیایند)
- از گوگل‌شیت عملیات (File → Download → xlsx): برگه‌های «متخصصین»، «نظر سنجی»، «شکایات از متخصصین»، «شکایات متخصصان»

وارد کردن دوباره‌ی یک فایل داده را تکراری نمی‌کند. شماره کارت و شبا عمداً وارد نمی‌شوند.

## وویس‌ها

- فعلاً: آپلود دستی در پنل (چند فایل با هم هم ممکن است).
- بعداً: یک اسکریپت روی کامپیوتر داخل شبکه‌ی شرکت ضبط‌های جولیو را به `POST /api/ingest/call/` می‌فرستد:
  ```
  curl -H "Authorization: Bearer $INGEST_TOKEN" -F audio=@call.wav -F kind=order -F agent=USERNAME -F customer_phone=09... https://crm.example.com/api/ingest/call/
  ```
- تبدیل به متن: ffmpeg → mp3 مونو ۱۶kHz → OpenRouter (`google/gemini-2.5-flash`). منطق از پروژه‌ی دست‌ساز کپی شده و به آن وابسته نیست.
- **حریم خصوصی:** فایل صوتی و متن مکالمه برای پردازش به OpenRouter/Gemini فرستاده می‌شود؛ ذخیره فقط روی سرور خودمان است.

## توسعه

```
pip install -r requirements.txt
DEBUG=1 python manage.py migrate && DEBUG=1 python manage.py seed_defaults
DEBUG=1 python manage.py test crm        # تست‌ها OpenRouter را شبیه‌سازی می‌کنند
DEBUG=1 python manage.py runserver
```
